# 🐍 Python Snake

A complete, desktop Snake Game built entirely with **Python** using the standard library (`tkinter`).

## 🚀 Features
- **100% Native Python**: No external dependencies or web technologies required.
- **Custom UI Rendering**: Uses Tkinter Canvas for custom anti-aliased menu buttons, grid lines, snake segments, and pulsating food effects.
- **Dynamic Score & Level Engine**: Real-time speed acceleration, multi-tiered food types (Normal, Bonus, Rare), and level transitions.
- **Configurable Settings**: Support for **Dark**, **Light**, and **Neon** visual themes, adjustable difficulties (Easy, Normal, Hard, Extreme), toggleable grid overlay, and audio toggle.
- **Local Persistence**: Automatic JSON file management (`settings.json` and `highscore.json`) with safe recovery fallbacks.

## 🕹️ Controls
- **W / ↑**: Move Up
- **S / ↓**: Move Down
- **A / ←**: Move Left
- **D / →**: Move Right
- **SPACE**: Pause / Resume
- **ESC**: Exit to Main Menu

## 🛠️ Running the Application

Ensure you have Python 3.8 or newer installed on your machine:

```bash
python main.py
